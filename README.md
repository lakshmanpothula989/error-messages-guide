Stop googling cryptic errors. **The Error Messages Guide** is a curated, searchable collection of the most common development errors across 10+ languages and frameworks. Each entry includes a plain-English explanation and a step-by-step solution.

---

## 🚀 Why This Guide?

We've all been there: `[object Object]`, `Segmentation fault (core dumped)`, or the dreaded `null is not an object`. This guide aims to reduce "debugging fatigue" by providing instant answers to the errors that haunt every developer.

### Categories Covered:
- **JavaScript/TypeScript:** `ReferenceError`, `TypeError`, `Async/Await` gotchas.
- **Python:** `IndentationError`, `KeyError`, `ImportError`.
- **PHP/Laravel:** `500 Internal Server Error`, `Class not found`, `Eloquent` issues.
- **SQL:** `Foreign key constraint fails`, `Deadlock found`.
- **Git:** `Merge conflicts`, `Detached HEAD`, `Non-fast-forward` push.
- **Docker/K8s:** `ImagePullBackOff`, `Container cannot be reached`.

---

## 📖 How to Use

Simply use `Cmd+F` (or `Ctrl+F`) on this README or browse the language-specific files in the `errors/` directory.

### Example: JavaScript `TypeError: Cannot read property 'x' of undefined`

**Explanation:** You are trying to access a property on a variable that hasn't been initialized or is explicitly `undefined`.

**Solution:**
1. Check if the object exists before accessing: `if (obj && obj.x)`.
2. Use Optional Chaining: `obj?.x`.
3. Set a default value: `const x = obj?.x || 'default'`.
